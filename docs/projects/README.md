# Project Portfolio Descriptions

This folder contains comprehensive, technical portfolio descriptions of software engineering projects.

- **[Society Mitr (सोसायटी मित्र) — High-Performance Housing Society ERP & AI Vehicle Gatekeeping Platform](./society-mitr.md)**: Enterprise-grade multi-tenant housing society management platform engineered with Rust (Axum, Tokio, SQLx), PostgreSQL, Python AI/ML microservice (FastALPR, ONNX, YOLOv8), Razorpay fintech integration, and automated CI/CD.
- **[ThinkX Panic Alarm System — Enterprise IoT & Cloud Backend](./thinkx-panic-alarm-backend.md)**: Real-Time IoT Cloud Backend & Edge Gateway engineered with Python (FastAPI), Rust (Tokio/Axum), PostgreSQL, Redis, and Celery.
- **[OpenUp Portal — On-Demand Emergency Roadside & Vehicle Lockout Platform](./openup-portal.md)**: On-demand emergency roadside assistance and automotive lockout dispatch platform built with Django REST Framework, MySQL, Celery, Redis, Google Distance Matrix API, Firebase Cloud Messaging (FCM v1), and multi-wallet payment vaulting (Stripe, PayPal Vault, Venmo, Apple Pay).
- **[Liliya WhatsApp CRM API](./liliya_whatsapp_crm_api.md)**: WhatsApp CRM Backend & Automation Service.
- **[Industrial Thermal Label & Barcode/QR Printing Desktop Suite](./industrial-label-printer-suite.md)**: Mission-critical industrial desktop hardware automation suite for high-speed thermal barcode & QR label printing engineered with Python 3, PyQt5, Ctypes Win32 FFI (`TSCLIB.dll`), Linux CUPS raw spooling, socket networking (TSPL Port 9100), vector rasterization (CairoSVG, Pillow), and PyInstaller standalone packaging.
- **[Tequila's Mexican Restaurant — Multi-Location Dining Loyalty, Rewards Ledger & Operations Platform](./tequila-restaurant-rewards-backend.md)**: Enterprise customer dining loyalty rewards ledger, dual-mode fraud-resistant claim verification (GPS check-in & receipt photo validation), geo-targeted asynchronous FCM push notifications via Celery & Redis, and full-featured administrative operations portal engineered with Python (Django & DRF), MySQL, and modular RBAC.
